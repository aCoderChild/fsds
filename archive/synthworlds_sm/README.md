# Archived SynthWorlds-SM pilots

`pilot_v1/` and `pilot_v5/` are superseded draft iterations retained for provenance. Neither is a training release. The active R1 workspace is `experiments/synthworlds_r1/`. The v2, v3, and v4 snapshots remain under `data/` because current validation and historical-result reproduction still depend on their source lineage.

`archive_index.json` records file counts, byte totals, and deterministic tree hashes from before the move.

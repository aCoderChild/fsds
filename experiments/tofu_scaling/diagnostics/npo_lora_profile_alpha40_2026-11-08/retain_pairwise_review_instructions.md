# Blinded answer review

For each question, compare responses A and B with the supplied reference answer. Rate each response independently; do not guess which system produced it. Assess semantic correctness rather than exact wording.

For factuality, use `correct`, `partly_correct`, `incorrect`, or `unclear`. For completeness, use `complete`, `partial`, or `insufficient`. Then choose A, B, `tie`, or `unclear` for overall quality, assign confidence 1–3, and note unsupported details or contradictions. If the reference answer seems ambiguous or insufficient, use `unclear` and explain.

The packet is intended for qualitative error analysis and is not designed to estimate benchmark-wide accuracy. The randomized response key is stored separately; do not request or open it until annotations are finished.

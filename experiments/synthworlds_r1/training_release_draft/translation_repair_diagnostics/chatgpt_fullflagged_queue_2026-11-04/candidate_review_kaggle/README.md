# SynthWorlds translation-repair review

Mode: `full799`; input rows: 799. This private Kaggle run generates NLLB-200 back-translations and Qwen2.5-14B semantic/fluency judgments for masked repair candidates. It sends no answers, split labels, or hidden facts. The output is AI-only diagnostic evidence; it does not approve translations or start training.
